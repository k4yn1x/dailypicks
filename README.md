# DailyPicks — football goal-market research board

A research board (not a betting service) that rates upcoming fixtures in eight
European leagues with a Dixon–Coles goal model, runs 10,000 coherent
posterior-predictive match simulations per fixture, and lists the markets that
survive a frozen ≥80% rule. Everything the board shows is generated by
`python -m dailypicks.pipeline`, which is designed to run unattended once a day.

## Layout

```
dailypicks/            Python package
  config.py            competitions, seasons, model / simulation / policy settings (versioned)
  teams.py             canonical team ids + alias table (bookmaker, ESPN and openfootball spellings)
  sources/openfootball.py   primary fixtures+results source, archived with hash + provenance
  sources/espn.py      independent fixture cross-check (teams, kick-off, status)
  ingest.py            sync -> archive -> validate -> atomic dataset swap
  store.py             SQLite dataset (rebuilt atomically) and immutable ledger; AsOfView guard
  model/dixon_coles.py Dixon–Coles fit (decay, L2, promoted prior, Laplace covariance), score grids
  model/priors.py      promoted-team priors from training seasons only
  simulate.py          posterior-predictive score simulation with explicit invalid-draw accounting
  markets.py           market definitions + coherent settlement (win / push / loss)
  select.py            frozen selection policy (80% rule, integer-line min win, primary line, cap)
  evaluate.py          walk-forward evaluation (log loss, Brier, calibration, blocked bootstrap)
  watchlist.py         ticket-team watchlist and coverage status
  pipeline.py          daily run: lock, stages, ledger, cross-check, atomic publish
site/index.template.html   single-file responsive frontend (data embedded at build time)
scripts/build_site.py      embeds data/published/latest.json into the page
scripts/daily.sh           scheduled entrypoint (05:30 America/Chicago gate)
scripts/tune_validation.sh hyper-parameter grid on the validation split only
tests/                     pytest suite
data/                      dataset (ignored), ledger.sqlite (kept), published/ (kept), watchlist/
```

## Running

```
pip install -r requirements.txt
python -m dailypicks.ingest                      # fetch + validate + publish dataset
python -m dailypicks.model.priors                # promoted priors (training seasons only)
python -m dailypicks.evaluate validation --xi 0.002 --l2 4 --tag try1   # tuning (validation only)
python -m dailypicks.evaluate test --tag frozen  # once, after freezing settings
python -m dailypicks.pipeline                    # daily board -> data/published/latest.json
python scripts/build_site.py                     # -> site/dist/index.html, standalone.html
python -m pytest -q
```

is and is not available in the current deployment.
